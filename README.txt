GITHUB PAGES DEMO PACKAGE

This folder is prepared for upload; it has not been published.

1. Sign in to GitHub and create a new PUBLIC repository named nexus-epc-demo.
   Enable the option to add a README so that the main branch is initialized.
2. Open the repository and choose Add file > Upload files.
3. Upload the CONTENTS of this folder into the repository root, including
   index.html, Prototype_Demo.mp4, captions.vtt, transcript.txt, and poster.png.
   Commit the uploaded files to main. Do not upload the ZIP as a single file.
4. Open Settings > Pages. Under Build and deployment, select Deploy from a
   branch, then main and /(root). Click Save.
5. Wait for deployment, then use the Visit site link shown in Settings > Pages.
   The default address is https://YOUR-USERNAME.github.io/nexus-epc-demo/.
   This is a template, not a verified live URL.
6. Open the live page in a private/incognito window and verify video playback,
   audio, and captions. Paste the working page URL into the Nexus application
   demonstration-video field.

GitHub Pages and this public repository will be viewable by anyone. This
package contains only the demonstration media, a player page, captions,
transcript, and attribution. The proposal/application documents are omitted.

The original MP4 is unchanged: 15,872,856 bytes, 147.55 seconds, 1920 x 1080.
English WebVTT captions are converted from the supplied SRT file.
